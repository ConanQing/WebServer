ConanWebServer

用 C++ 从零手写的高并发 HTTP 服务器

服务器运行中 · Linux · 端口 8080
C++17 epoll Edge-Triggered Non-blocking I/O Keep-Alive CMake

核心特性

01

epoll + ET

事件驱动，单线程监听海量连接；边缘触发配合非阻塞 I/O，事件不丢、不轮询

02

Keep-Alive

长连接复用：一次握手服务多个请求，响应头如实告知客户端连接去向

03

非阻塞收发

每个连接配独立读写缓冲，send / recv 循环到底，20MB 文件分毫不差

04

静态文件服务

按请求路径返回 www/ 下的文件，路径不存在时返回 404 兜底页
